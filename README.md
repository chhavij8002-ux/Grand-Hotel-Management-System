#  Grand Hotel - Hotel Booking System

##  Project Description

**Grand Hotel** is a simple Python-based hotel booking system. It allows users to enter their personal details, select a room type, choose a bed size, and calculate their booking details.

This project is designed as a beginner-friendly Python project to practice **input, conditional statements, loops, and validation**.

##  Features

* Enter customer's name
*  Validate the customer's phone number
*  Choose a room type
*  Choose a bed size
*  Calculate room charges
*  Handle invalid choices using validation loops
*  Display booking information

##  Available Rooms

| Choice | Room Type     | Price |
| ------ | ------------- | ----: |
| 1      | Standard Room | ₹2000 |
| 2      | Deluxe Room   | ₹3500 |
| 3      | Suite Room    | ₹5000 |

##  Available Bed Sizes

| Choice | Bed Size      |
| ------ | ------------- |
| 1      | Single Bed    |
| 2      | Double Bed    |
| 3      | King Size Bed |

##  Input Validation

The program validates the customer's phone number to make sure that:

* The phone number contains exactly **10 digits**.
* Only numerical digits are accepted.

The program also checks that the selected room and bed choices are valid.

##  Technologies Used

* **Python 3**
* `input()`
* `print()`
* `while` loops
* `if-elif-else` statements
* String methods such as `.isdigit()`
* Basic variables and arithmetic operations

##  How to Run

### 1. Install Python

Make sure Python 3 is installed on your computer.

### 2. Download or Clone the Repository

Clone the repository using:

```bash
git clone YOUR_GITHUB_REPOSITORY_LINK
```

### 3. Open the Project Folder

```bash
cd grand-hotel
```

### 4. Run the Program

If your Python file is named `hotel.py`:

